# python-learning

Advanced Python exercises — built while completing the [ZTM Complete Python Developer](https://zerotomastery.io/courses/learn-python/) course (68% complete).

## Topics covered

| File | Topic |
|---|---|
| `decorators.py` | Function decorators, `@wraps`, parameterized decorators |
| `generators.py` | `yield`, generator expressions, lazy evaluation |
| `list-comprehensions.py` | List, dict, set comprehensions with conditions |
| `dictionary-comprehensions.py` | Dict comprehensions, nested structures |
| `lambda-expressions.py` | Lambda, `map`, `filter`, `sorted` with key |
| `error-handling.py` | `try/except/finally`, custom exceptions |
| `working-with-files.py` | File I/O, context managers, `pathlib` |
| `randomgame.py` | Mini project — number guessing game |

## Directories

- `break-the-ice/` — Exercises from [break-the-ice-with-python](https://github.com/darkprinx/break-the-ice-with-python)
- `utility/` — Shared utilities used across exercises

## Environment

```bash
# Activate the project venv (uv)
source .venv/bin/activate

# Run a script
python decorators.py

# Run tests
pytest
```

**Stack:** Python 3.12 · uv · pytest
